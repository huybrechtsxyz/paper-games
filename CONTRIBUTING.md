# Contributing

Thanks for helping to improve the paper games!

## Ideas and changes

- **Open an issue** to suggest a new monster, item, rule change or a whole new game.
- **Open a pull request** for fixes and additions. Keep each pull request small and focused.

## Guidelines for new content

- **Every item must do something in the game.** No item is only decoration.
- Keep the game quick: a turn should take seconds, and a game a few minutes.
- Use a standard dice set (d4, d6, d8, d10, d12, d20, percentile die) and as little other material as possible.
- When you add to a table, make sure the dice ranges still cover the whole die with no gaps or overlaps.
- If you change numbers, check the balance with `tools/paper-dungeon-tables.xlsx` and mention the new odds in your pull request.

## Style

- Write rules in short, plain sentences.
- Use tables for anything you roll on.
- Games go in `games/`, with the name in lowercase and hyphens, for example `paper-trail.md`.
